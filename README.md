# 🏛️ Documentação do Modelo de Dados Analítico (Branch Principal)

Este é o repositório oficial e estável do projeto **DocumentacaoPbi**. Esta branch contém apenas versões validadas e prontas para o consumo do usuário final.

---

## 🚀 Visão Geral
A branch `principal` (main) representa o ambiente de **Produção**. Todo o código contido aqui é o que alimenta os relatórios executivos da empresa.

---

## 📂 Estrutura do Repositório
* **README.md**: Guia geral de arquitetura (este arquivo).

---

## 🛡️ Regras de Governança

Para garantir a estabilidade dos relatórios, seguimos estas diretrizes:

1. **Acesso Restrito**: Edições diretas nesta branch são bloqueadas.
2. **Ciclo de Atualização**: As mudanças só chegam aqui via **Pull Request (PR)** vindo da branch `dev`.
3. **Validação**: Nenhum PR é aprovado sem que as medidas DAX tenham sido testadas e conferidas com os valores de origem.

---

## 🛠️ Como Contribuir

Se você faz parte do time de Estratégia ou BI e precisa realizar uma alteração:

1. Mude para a branch `dev` no seu Workspace do Power BI.
2. Realize as alterações e faça o **Commit** com uma mensagem clara.
3. Após a validação técnica, solicite a integração das mudanças para a `principal` através de um Pull Request no GitHub.
